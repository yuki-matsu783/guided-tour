自分で作ったツアーは、サイドパネルの「ツアー一覧」の画面から取り込めます。

## 一覧の開き方

ツアーを実行しているときや一時中断しているときは、サイドパネル右上の「ツアーの一覧」を押すと、一覧が開きます。一覧には、取り込み・削除・「再読み込み」があります。実行中は、ツアーの開始のボタンは出ません。元の画面へは、「実行中の画面へ戻る」（一時中断中は「一時中断中の画面へ戻る」）で戻れます。

## 取り込み方

一覧の「ツアーを取り込む」の欄（取り込みエリア）に、ファイルをドロップします。「ファイルを選ぶ」で選んで取り込むこともできます。複数のファイルを同時に取り込めます。取り込みの結果は、取り込みが続いている間に画面を移っても、一覧に戻ると表示されます。「結果を閉じる」で消せます。

- 取り込めるのは、`.yaml` のファイルと、`.zip`（ツアーパッケージ）です

## 同じ ID があるとき

同じ ID のツアーがあると、上書きの確認が出ます。確認には、ファイル名とツアーの名前と ID が出ます。同梱のツアーを置き換えるときは、その旨も表示されます。実行中のツアーを上書きすると、そのツアーは一時中断になります。

## 誤りがあるとき

ファイル名、行番号、理由が表示され、取り込まれません。直してから、もう一度取り込んでください。

## 削除

取り込んだツアーは、一覧の「削除」で削除できます。実行中のツアーを削除すると、ツアーは終了します。同梱のツアーは削除できません。同梱と同じ ID のツアーを取り込んだ場合は、削除すると同梱版に戻ります。

保存できる容量には上限があります。
