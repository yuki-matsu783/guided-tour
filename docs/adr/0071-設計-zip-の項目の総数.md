# ADR-0071: zip の項目の総数（設計書）

状態: 採用

## 決めたこと

- ツアーパッケージの zip の項目（ファイル・ディレクトリ・名前の不正な項目のすべて）の総数を 2,000 までとし、超えた時点で展開を打ち切って拒否する
- ファイル数の上限（500）は変えない。ディレクトリの項目はファイル数に数えない

## 理由

- ディレクトリの項目は1件が数十バイトで、ファイル数に数えないと、20 MB の zip に数十万件を詰められる。実測で 40 万件の取り込みに 72 秒かかり、取り込みの間の処理が長く止まった
- 普通のツアーのディレクトリは数個で、総数 2,000 は実際のツアーの妨げにならない（利用者の判断）

## 得たもの・失ったもの

- 取り込みにかかる手間が、項目の総数で抑えられる
- 上限値が1つ増える

## 採らなかった案

- ディレクトリもファイル数（500）に数える案。上限は1つで済むが、ディレクトリの多いツアーが、ファイルが少なくても取り込めなくなる
