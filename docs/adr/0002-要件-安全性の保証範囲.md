# ADR-0002: 安全性の保証範囲（要件書）

状態: 採用

## 決めたこと

「仕組みで防ぐ」6項目に絞る。ページ自身の通信や利用者の操作に伴う通信、指示内容の正しさなどは保証しない

## 理由

社内ツールとして悪意はある程度許容し、本当に危険なことだけを防ぐため（利用者の方針）。外部送信の範囲はレビューの指摘
