# ADR-0047: 状態の確定（設計書）

状態: 採用

## 決めたこと

storage.session への書き込みを確定の時点とし、外への作用はその後に行う。進捗は gen で古い書き込みを捨てる。終了は印を残し、削除の失敗はやり直す

## 理由

再起動をまたいでも巻き戻りや進捗の復活を起こさないため（レビューの指摘）
