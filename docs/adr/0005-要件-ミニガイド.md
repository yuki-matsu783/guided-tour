# ADR-0005: ミニガイド（要件書）

状態: 採用

## 決めたこと

サイドパネルに加えて、ページ右端にミニガイドを出す。展開・最小化（右端のバー）・ホバーを切り替えられ、幅を変えられる。設定はツアーをまたいで保持する

## 理由

サイドパネルは最小化やホバーができないため（利用者の要望）
