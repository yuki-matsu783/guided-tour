# ADR-0072: 同梱版が残る削除（設計書）

状態: 採用

## 決めたこと

実行中のツアーの取り込み版が削除されたら、同じ ID の同梱版が残っていても終了する（表示と進捗を消す）。上書きによる一時中断にはしない。

## 理由

- 要件書は、実行中のツアーが削除されたら終了する（FR-36）、取り込み版を削除したら同じ ID の同梱版が再び使われる（FR-06）とし、両方に当たる場合を決めていない
- 利用者が行ったのは削除で、結果も削除として見えるほうが、操作と結果が一致して分かりやすい（利用者の判断）
- 同梱版は一覧に戻るので、続けたければ一覧から開始し直せる

## 採らなかった案

- 同梱版による上書きとして一時中断し、同梱版で続きから・最初から・終了を選ばせる案。続きから再開できるが、削除したのにツアーが続いているように見える
