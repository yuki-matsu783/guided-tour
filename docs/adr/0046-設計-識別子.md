# ADR-0046: 識別子（設計書）

状態: 採用

## 決めたこと

`sessionId`・`gen`・`pageSeq`・`rev`・`opId` と `sender` で判定する。操作の種類ごとに必要な一致を決める

## 理由

同じタブの別の文書、古い指示、古いパネルからの操作を区別するため（レビューの指摘）
