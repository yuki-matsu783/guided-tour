# ADR-0031: 表示内容（要件書）

状態: 採用

## 決めたこと

サイドパネルは Markdown（許可リスト方式、HTML は文字列のまま）と画像（PNG・JPEG・WebP・GIF）。吹き出しとミニガイドは短い文字列

## 理由

信頼できないツアーでも安全に表示でき、処理も単純になるため
