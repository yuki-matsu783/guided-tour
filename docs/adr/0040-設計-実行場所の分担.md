# ADR-0040: 実行場所の分担（設計書）

状態: 採用

## 決めたこと

状態はバックグラウンドだけが持つ。取り込みとファイルの表示はサイドパネルで行う。ページ側は報告と、利用者の実際の操作の中継だけを行う

## 理由

状態を変える経路を絞るため。Service Worker の API の制約と、重い処理で状態管理を止めないため（レビューの指摘）
