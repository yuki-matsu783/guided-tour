# ADR-0073: 移動の直後の操作の受け付け（設計書）

状態: 採用

## 決めたこと

- ミニガイドとサイドパネルは、移動の操作（次へ・戻る・完了・一覧からの移動）を送ったら、新しい表示が届くまで、次の移動の操作を送らない
- 新しいステップの表示が届いてから 500 ミリ秒の間は、その表示への移動の操作を受け付けない
- バックグラウンドの、同じ表示（`gen`）からの操作を1回だけ受け付ける規則は変えない

## 理由

- 同じ表示からの重複は `gen` で捨てられる。しかし、連打の途中で新しいステップの表示が届くと、その後のクリックは新しい表示からの最初の操作として受け付けられ、2ステップ進んでいた（E2E の E-11 で、負荷の高いときに再現した）。AC-11 は、連打しても1ステップだけ進むことを求めている
- 新しい表示を見てから押したのではない操作を見分けるには、表示が届いてからの時間で区切るしかない。500 ミリ秒は、人が意図して続けて2回押す間隔より短くはないが、連打を1回にまとめるには足りる長さとして選んだ

## 得たもの・失ったもの

- 連打やほぼ同時の操作で、二重に移動しない
- 表示が切り替わった直後の 500 ミリ秒は、意図した操作でも移動できない

## 採らなかった案

- バックグラウンドで、直前の移動からの時間で捨てる案。サイドパネルとミニガイドで同じ規則になるが、表示がいつ利用者に届いたかをバックグラウンドは知らない
