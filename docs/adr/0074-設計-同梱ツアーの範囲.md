# ADR-0074: 同梱ツアーの範囲（設計書）

状態: 採用

## 決めたこと

- 本版で同梱するツアーは、この拡張機能自体の使い方を案内する自己紹介ツアー（`guided-setup-tour-intro`）1本とする。練習用のページには `https://example.com/` を使う
- ADR-0068 の「同梱ツアーの3本を schemaVersion 3 の YAML で書き直す」は、元の資料が揃ったときに行う。それまでは、英語表示の GitLab での確認（AC-38）を、GitLab 風のテスト用ページとテスト用のツアーによる E2E で行い、実際のサイトでの確認は手動とする

## 理由

- 既存実装と同梱3ツアーの元の資料がリポジトリに無く、書き直す元が無い（利用者の判断）
- 利用者は、この仕組み自体の使い方を案内するツアーを組み込むことを求めた。ページ上の表示（ミニガイド・ハイライト・吹き出し・完了の目安）を体験させるには、http/https の実在のページが要る。`example.com` は構造が最小で、表記が変わっても名前の候補と文章だけの案内で体験が壊れない

## 得たもの・失ったもの

- 初めて使う人が、拡張機能の使い方を体験しながら学べる
- 同梱3ツアーによる実際のサイトでの確認は、元の資料が揃うまでできない
- 自己紹介ツアーは外部のページに頼るので、表記の変更や到達できない環境では、ハイライトの代わりに文章だけの案内になる
