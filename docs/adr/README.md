# ADR

設計・実装の経緯を残す。1つの決定を1枚にする。何を書くかの切り分けは[要件書・設計書・ADRの書き分け](../claude/docs-writing.md)にある。

## 1枚の形

- ファイル名は `NNNN-<対象>-<題>.md`。番号は連番で、欠番を詰めない
- 見出しは `# ADR-NNNN: <題>`。続けて `状態:` の行
- `## 決めたこと`、`## 理由` は必須。分かっていれば `## 得たもの・失ったもの`、`## 採らなかった案` を足す。分からないことは書かず、空の節も作らない
- 日付は書かない（git の履歴が持つ）

## 状態

| 状態 | 意味 |
|---|---|
| 採用 | いま有効 |
| 置き換え | 新しい1枚に覆された。本文は書き換えず、状態の行に置き換え先を書く |

覆すときは新しい1枚を足し、古い側の状態だけを「置き換え」にする。消さない。
