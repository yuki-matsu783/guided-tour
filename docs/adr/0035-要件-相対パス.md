# ADR-0035: 相対パス（要件書）

状態: 採用

## 決めたこと

参照元ファイルの場所を起点にする。参照では、パッケージの中に留まる範囲で `..` を許す。zip のファイル名では `..` を拒否する

## 理由

エディタのプレビューで確認できるようにし、zip の細工を防ぐため
