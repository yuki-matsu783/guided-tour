# ADR-0056: ミニガイド（設計書）

状態: 採用

## 決めたこと

閉じた Shadow DOM の中に、展開・最小化・ホバーの3つの状態で描く。設定は storage.local に保存し、描画指示で全タブに配る

## 理由

利用者の要望。ページのスクリプトから操作されないようにするため
