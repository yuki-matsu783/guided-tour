# 単体テストケース一覧：要素特定・Markdown・ロガー・保守記録

利用者の承認を得てから実装に使う。テストコードはまだ書かない。方法は Vitest（要素特定・Markdown は jsdom。表示の判定と読み上げ名は `env` で差し替える。ロガー・保守記録は fake-indexeddb と偽のタイマー）。

「根拠」の略称：設計＝設計書の節名。
